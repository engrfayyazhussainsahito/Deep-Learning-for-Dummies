## Why this course

Most deep learning material falls into two camps: quick tutorials that skip the math, or dense textbooks with no code. This course tries to be both rigorous and hands-on, in one coherent path.

| | |
|---|---|
| **Math you can follow** | Derivations are done step by step, intuition first, every symbol defined. Backpropagation, ELBOs, attention and policy gradients are all worked through. |
| **Code that runs** | From-scratch NumPy to idiomatic PyTorch and Hugging Face. Every lab is small enough for a free Colab GPU and complete enough to learn from. |
| **Interactive by design** | Drag a learning rate, step through attention, push a GAN into mode collapse. Demos run entirely in your browser, offline, with no accounts. |
| **Basics to the frontier** | Perceptrons to Transformers, LLMs, diffusion, graph networks, deep RL, scaling, safety and theory. |

## Highlights by week

<details>
<summary><b>Click to expand: what each week covers</b></summary>

- **Week 1:** What deep learning is and where it came from; a self-contained refresher of linear algebra, calculus, probability and information theory; a working PyTorch toolkit.
- **Week 2:** The perceptron to multilayer networks, universal approximation, activation and loss functions, a full derivation of backpropagation and autodiff, and a from-scratch NumPy lab.
- **Week 3:** Why training is a hard non-convex problem; SGD, momentum, Adam/AdamW, learning-rate schedules, initialization, clipping and normalization layers.
- **Week 4:** Weight decay, dropout, label smoothing, early stopping, mixup and CutMix; hyperparameter search, debugging, logging, checkpointing and honest evaluation.
- **Week 5:** Locality, weight sharing and equivariance; convolution arithmetic; conv-layer gradients; LeNet, AlexNet, VGG; a CIFAR-10 classifier.
- **Week 6:** Residual learning, ResNeXt, DenseNet, Inception, MobileNet, EfficientNet, ConvNeXt; transfer learning; detection (R-CNN family, SSD, YOLO) and segmentation (FCN, U-Net, DeepLab, Mask R-CNN).
- **Week 7:** RNNs, backpropagation through time, vanishing/exploding gradients, LSTM and GRU, seq2seq, and the attention mechanism that made recurrence optional.
- **Week 8:** word2vec, GloVe, fastText, embedding geometry and bias, BPE/WordPiece/Unigram tokenization, contrastive and InfoNCE losses, plus a Weeks 1 to 7 review and practice midterm.
- **Week 9:** Self-attention from first principles, multi-head attention with exact tensor shapes, positional encodings (sinusoids to RoPE and ALiBi), parameter and FLOP counting, and a from-scratch GPT in PyTorch.
- **Week 10:** BERT, GPT and T5 objectives, scaling laws, LoRA/QLoRA, instruction tuning, in-context learning, SFT, RLHF and DPO, RAG, evaluation, decoding, and a Hugging Face lab.
- **Week 11:** ViT, DeiT, Swin, DETR, SAM; SimCLR, MoCo, BYOL, DINO, MAE; CLIP and multimodal LLMs; a lab on fine-tuning, CLIP retrieval and linear probing.
- **Week 12:** Autoencoders, VAEs with a full ELBO derivation, VQ-VAE, GANs (WGAN-GP, DCGAN, CycleGAN, StyleGAN), IS/FID; a VAE and DCGAN lab on MNIST.
- **Week 13:** Denoising diffusion from first principles, score matching, DDIM, classifier-free guidance, latent diffusion with U-Net and DiT, flows and autoregressive models; a class-conditional DDPM lab.
- **Week 14:** Message passing, GCN, GraphSAGE, GAT, GIN, the Weisfeiler-Lehman test, over-smoothing, graph Transformers, and the geometric deep learning blueprint; a PyTorch Geometric lab.
- **Week 15:** MDPs, Bellman equations, Q-learning, DQN, policy gradients, actor-critic, GAE, TRPO/PPO, DDPG/TD3/SAC, offline RL, and the link to RLHF/DPO/GRPO; DQN and PPO labs.
- **Week 16:** Roofline model, profiling, mixed precision, parallelism, ZeRO/FSDP, FlashAttention, KV caching, pruning, quantization, distillation, MoE, and deployment; a profiling and optimization lab.
- **Week 17:** Adversarial examples, OOD detection, uncertainty and calibration, interpretability, fairness, privacy and DP-SGD, theory highlights (NTK, lottery tickets, grokking, double descent); an attack, defense and Grad-CAM lab.
- **Week 18:** Project talk and report guide, reproducibility checklist, cumulative review, a 43-question practice final with solutions, and next steps for reading papers and careers.

</details>

## How to study with this course

1. **Read actively.** Try each derivation on paper before opening the collapsed solution.
2. **Play with every demo.** Change one thing at a time and predict the outcome before you look.
3. **Run the labs.** Copy the code into Colab or a local environment and break it on purpose.
4. **Do the exercises.** They run from warm-up to research-flavoured; the hard ones are where learning happens.
5. **Read the papers.** Each week ends with essential reading marked. Skim first, then read closely.

Your progress is saved in your browser, so you can pick up where you left off.

## Prerequisites and setup

**You should know:** linear algebra, multivariate calculus, probability, Python/NumPy, and the basics of machine learning. Week 1 includes a compact math refresher.

**You need:** Python 3.10+, PyTorch, and a free Google Colab account. That is enough for every lab.

## Run it locally

The site is plain static HTML, so any static file server works.

```bash
git clone https://github.com/engrfayyazhussainsahito/Deep-Learning-for-Dummies.git
cd Deep-Learning-for-Dummies/dl-course/site

# Any one of these:
python -m http.server 8000
# or
npx serve .
```

Then open <http://localhost:8000>. Math is rendered with a bundled copy of KaTeX, and the demos run offline.

## Deployment

Every push to `main` triggers the GitHub Actions workflow in `.github/workflows/pages.yml`, which publishes `dl-course/site` to GitHub Pages. In the repository settings, Pages must use **Source: GitHub Actions**.
